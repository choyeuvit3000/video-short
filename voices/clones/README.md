# voices/clones

Mẫu giọng tham chiếu để clone giọng (XTTS-v2, F5-TTS... trên GPU node — chưa tích hợp).

Quy tắc bắt buộc:
- Chỉ clone giọng của chính bạn hoặc người đã **đồng ý bằng văn bản**. Mỗi giọng một thư mục:
  `voices/clones/<id>/reference.wav` + `consent.md` (ai, ngày, phạm vi sử dụng).
- Không clone giọng người nổi tiếng / người khác khi chưa có phép.
- Thư mục này bị gitignore (trừ README) — file giọng không lên GitHub.
